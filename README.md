# Solvers (Tempo)

Solvers is a marketplace of AI specialists ("Solvers") that plug into Claude and ChatGPT through a single MCP connector. A
Solver is a data package (method steps with checklists, knowledge base, templates, evals), not code. Buying one mints a
**license NFT** (ERC-721) to the buyer's wallet; reviews, pay-per-use credits, milestone guarantees (escrow), creator staking,
the license supply cap and a transfer royalty are enforced by smart contracts on **Tempo**, a payments-focused EVM chain with
no native gas token: fees are paid in stablecoins and the platform sponsors them, so buyers and agents never need gas.

This repository is the Tempo rebuild of the original Solvers app. It runs on the Tempo testnet **Moderato** (chain id 42431;
contracts verified, addresses in `deployments/42431.json`); mainnet (4217) waits for the owner's decisions listed in
`docs/migration/decisions.md`. The rebuild is tracked in `docs/migration/` (`progress.md` says where it stands).

## How it works

- **Licenses** are ERC-721 tokens. Transferring one pays an on-chain **royalty** on the original price (a per-Solver creator
  share, 5% for most packages, plus a 5% platform share by default; total capped at 25%), enforced by the contract. A
  transfer never frees a slot of the license cap.
- **Payments** are in a TIP-20 USD stablecoin (6 decimals). Every purchase is at least 5 units; the platform fee (10% by
  default) is taken at purchase and the rest goes straight to the creator. Network fees are never deducted.
- Buyers pay from their **wallet** (one sponsored batch: approve + purchase), by **Pix** (the platform buys on-chain for them
  from its stablecoin float; simulated on testnets), or, for AI agents, over **HTTP 402 with the Machine Payments Protocol**.
- Sign-in is **SIWE** (Sign-In with Ethereum); people log in by e-mail with Privy and get an embedded EVM wallet; MCP clients
  use OAuth (dynamic registration + PKCE); agents with a key log in with two HTTP calls.

## Layout

| Path | What |
|---|---|
| `contracts/` | Foundry project: `SolversRegistry`, `SolversLicense`, `SolversCredits`, `SolversReviews`, `SolversEscrow`, `SolversStaking` (UUPS), tests, deploy/upgrade scripts |
| `deployments/` | Deployed addresses per chain id |
| `packages/contracts-client` | ABIs + deployment addresses generated by `@wagmi/cli` |
| `packages/chain` | viem clients, call builders, relay policy and handler, server sends, event and error decoding |
| `packages/shared` | zod data contract and pure rules shared by server and web |
| `packages/api-client` | typed API client used by the web app and scripts |
| `apps/server` | Express API, MCP connector, OAuth, relay, indexer, payments, agent-pay, creator flow, worker |
| `apps/web` | Next.js app (Privy login, embedded EVM wallet, English with `/pt`) |
| `agents/` | Solver packages (data) |
| `scripts/` | local bootstrap, top-up, e2e, smoke and eval scripts |
| `infra/` | environment template, PM2, nginx and manual deploy scripts (see `infra/README.md`; nothing deploys automatically) |
| `docs/` | documentation, index in `docs/README.md` |

## Development

```bash
pnpm install
pnpm build && pnpm typecheck && pnpm test
cd contracts && forge test                     # Foundry >= 1.8.5 with Tempo support
cd scripts && npx tsx src/bootstrap.ts --seed  # local anvil --tempo + contracts + QA database
```

See `CLAUDE.md` for the full command list and rules, `docs/architecture.md` for the design, `docs/qa.md` for testing and
`docs/deploy-runbook.md` for deployment.
