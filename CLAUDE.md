# CLAUDE.md

Guidance for Claude Code (claude.ai/code) in this repository.

## What this is

Solvers is a marketplace of AI specialists ("Solvers") that plug into Claude and ChatGPT through one MCP connector. A Solver is a
data package (method steps with checklists, knowledge base, templates, evals), not code. Buying one mints a **license NFT
(ERC-721)** on **Tempo** (EVM, no native gas token, fees in TIP-20 stablecoins, sponsored batched transactions). Reviews, credits,
milestone guarantees (escrow), creator staking, the supply cap and the transfer royalty are enforced by six UUPS contracts.
Buyers pay from a wallet (the platform relay sponsors the fee), by Pix (the platform buys on-chain for them from its float) or,
for AI agents, over HTTP 402 with MPP. Everything runs on the Moderato testnet; mainnet waits for the owner's decisions.

**The rebuild on Tempo is finishing (phases 7-8).** Read `docs/migration/progress.md` first (what is done, what is next, how to
resume), then `docs/migration/decisions.md` (D1-D20, deviations X1-X34, decisions the owner owes). The approved plan and the old
repository (the reference implementation, **read-only**: never edit, build, install, commit or run formatters there)
live outside this repository; their paths on the dev machine are in `CLAUDE.local.md` (gitignored).

Also read `AGENTS.md` (Solidity/Foundry/viem/Tempo rules) and `apps/web/AGENTS.md` (Next.js 16 differs from training data:
check `apps/web/node_modules/next/dist/docs/` first). Docs and code are in English; the web app keeps `en` + `pt` messages.
Start with `docs/architecture.md` for how the pieces fit.

## Stack

- **Monorepo**: pnpm 10.20 + Turborepo 2.11 (`agentGuidance: false`), Node >= 22, TypeScript, `tsx`, tests with `node:test`.
- **Contracts** (`contracts/`): Solidity 0.8.30, Foundry 1.8.5 (`tempo = true`, `evm_version = "osaka"`), OpenZeppelin v5.7
  upgradeable, UUPS + ERC-7201 storage, `openzeppelin-foundry-upgrades`, `tempo-std`.
- **Chain client**: viem 2.57 (`viem/tempo`, `viem/chains` `tempo` / `tempoModerato`), ABIs generated by `@wagmi/cli`.
- **Server** (`apps/server`): Express 5, Drizzle + Postgres 16 with pgvector, `@modelcontextprotocol/sdk`, `jose`, SIWE
  (`viem/siwe`), `zod`, `sharp`, local embeddings (`@huggingface/transformers`), MPP (`mppx`).
- **Web** (`apps/web`): Next.js 16 App Router + React 19, Privy (e-mail login, embedded EVM wallet via
  `@privy-io/react-auth/tempo`), viem, next-intl.
- **External services**: Tempo RPC, Privy, Mercado Pago (Pix), Cloudinary, Telegram, Docker (deliverable verifier sandbox).

```bash
pnpm install
pnpm build && pnpm typecheck && pnpm test           # root, via turbo
node scripts/purge-check.mjs [--literal] [--list]   # previous-chain vocabulary gate (only docs/migration/00-inventory.md may match)

pnpm --filter @solvers/contracts-client generate    # after a contract or deployment change (generate:check in CI)
pnpm --filter @solvers/server dev                   # API on 3018, reads apps/server/.env
pnpm --filter @solvers/server worker:dev            # creator-flow worker
pnpm --filter @solvers/web dev                      # web on 3001 (apps/web/.env.local)
pnpm --filter @solvers/server db:generate | db:migrate
cd apps/server && node --env-file-if-exists=.env.test --import tsx --test test/trial.test.ts   # one server test
cd packages/shared && node --import tsx --test src/money.test.ts                               # one package test

pnpm --filter @solvers/server cli:publish [slug...] | --no-chain   # platform packages (--no-chain for PLATFORM_AGENTS)
pnpm --filter @solvers/server cli:invite create --email x@y.com      # no extra `--` with pnpm
pnpm --filter @solvers/server cli:approve <slug|submissionId> [--dry-run] [--key-file <file>]
pnpm --filter @solvers/server cli:suspend <slug> [--resume] [--reason "..."]
pnpm --filter @solvers/server cli:admin <command> [--yes]            # governance; dry-run unless --yes
pnpm --filter @solvers/server cli:reindex --dead | --tx <hash> | --from-block N
pnpm --filter @solvers/server cli:treasury-status | cli:ledger-export --from <day> --to <day>

cd scripts && npx tsx src/bootstrap.ts --seed      # local anvil --tempo + contracts + .env.qa + QA DB
cd scripts && npm run e2e:purchase                 # also e2e:api|full|mcp|creator|supply|pix|transfer|agent-pay|agent-use (docs/qa.md)
cd scripts && npm run eval [slug]
```

DB tests (`*.db.test.ts`) run only with `TEST_DATABASE_URL` pointing to the disposable `solvers_tempo_test` on 5546.
Authenticated route tests need no Privy or chain: `createApp([])` + `signSession(wallet)` from `auth/jwt.ts`.

Contracts (`cd contracts`; Foundry 1.8.5 in `~/.foundry/bin`, add it to PATH):

```bash
forge build --sizes --skip test --skip 'test/**'   # sizes must stay < 24,576 bytes (test helpers excluded)
forge test                             # FOUNDRY_PROFILE=ci for fuzz 2000 / invariants 256 x 64
forge snapshot --check --no-match-path 'test/invariant/*' --no-match-test 'Fuzz|fuzz'
node script/check-layouts.mjs          # storage layouts append-only (--write after a reviewed change)
bash script/e2e-anvil.sh               # fresh anvil --tempo: validated deploy + sponsored flows
```

Always `forge clean` right before a deploy/upgrade script: the OZ upgrade validator needs exactly one build-info per
contract. Deployment, verification and the upgrade procedure: `docs/deploy-runbook.md`.

## Rules that are not obvious from the code

- Nothing outward-facing without the owner: no `git push`, no remote, no VPS/nginx/PM2/DNS/certbot change, no mainnet
  transaction, no real funds, no third-party account or dashboard change (Privy, Mercado Pago). Moderato transactions and the
  public faucet are fine. A deploy workflow, when added, is `workflow_dispatch` only.
- Keys and `.env*` never enter git (`apps/server/.keys`, gitignored; templates `infra/.env.example`, `apps/web/.env.example`).
  On mainnet the server refuses `ADMIN_PRIVATE_KEY`, `GUARDIAN_PRIVATE_KEY`, `DEPLOYER_PRIVATE_KEY`; admin CLIs need
  `--key-file` there. RELAY (fee payer, no role) must differ from PLATFORM and VERIFIER off the local chain.
- Every purchase (license, credits, guarantee) is >= `minPrice` (default 5 stablecoin units = `5 * 10^6` base units; TIP-20
  tokens have 6 decimals). Network fees are paid by the RELAY key and never deducted from any split. Primary-sale fee: floor,
  remainder to the creator (`docs/economics.md`). Transfer royalty (D15): creator share per Solver (manifest `royaltyBps`,
  editable only before the first sale) + platform share (Registry config), both bps of the ORIGINAL price, each floored, total
  capped at 25%, paid by the transferring owner (`docs/royalties.md`). Defaults 5% + 5% are still owed decision #2.
- The license cap is enforced by the contract (`SoldOut`); it can only be raised and burning or transferring never frees a slot.
  Never say "only N will exist" (`docs/license-cap.md`).
- Evals are version-scoped (D6): `updateVersion` never zeroes anything; a new version reads as "not measured" until `setEval`
  for its `versionHash`. A rating label is "internal team test", never "verified" (`apps/web/src/lib/eval-label.ts`).
- Approving on the site (`ADMIN_WALLETS`) signs nothing on-chain: new Solvers need `cli:approve` (cold admin key, fee by RELAY);
  suspending needs `cli:suspend` (DB + `suspendAgent`).
- The worker is another process (`solvers-tempo-worker`) and holds no chain key; a stopped worker leaves submissions in
  `submitted`/`validating`.
- `PLATFORM_AGENTS` (`apps/server/src/runtime/platform-agents.ts`) is the only authority for free platform Solvers (DB only).
- Agent-pay keeps `mppx` replay state in memory: run a single API process.
- Contract storage is append-only (`AGENTS.md`); migrations must stay backward compatible with the running release.
- No tax or legal conclusions in code or docs; open questions go to `docs/payments-open-questions.md`.
