## End to end on `anvil --tempo` (`bash script/e2e-anvil.sh`)

Fresh anvil → `forge clean` → `Deploy.s.sol` (validated) → `AcceptAdmin.s.sol` → sponsored flows (each receipt's
`feePayer` = sponsor, senders pay no fee): register with stake, approve, purchase (buyer pays exactly 10,000,000; creator
9,000,000; treasury 1,000,000), transfer with royalty (owner pays exactly 1,000,000; creator 500,000; platform 500,000),
`purchaseLicenseFor` from the platform float, escrow create → markPassed → release (creator 6,300,000), then an atomic
self-paid `0x76` batch `[approve, purchaseLicense]` and a batch whose second call reverts (the approve is rolled back).
Result: `ALL E2E CHECKS PASSED`. Foundry CLI limits found on the way are recorded as X19.

## Lint

`forge lint src` is clean. Excluded lints, with reasons in `foundry.toml`: `reentrancy-events` (events after calls to our own
contracts or the TIP-20 precompile, which never call back; every state-changing entry point is `nonReentrant`),
`block-timestamp` (deadlines/windows are protocol semantics), `unsafe-typecast` (bounded casts, tested). Four intentional
patterns are annotated inline (`arbitrary-send-erc20` in `_pullIn`, exact balance-diff equality, a revert in the ≤5 loop).
